## 📖 Overview

**ToolForge** is a unified platform where users discover, run, and compose AI-powered tools into reusable workflows.

### 🎯 Vision
- Centralized marketplace for AI tools
- Schema-driven configuration (no code needed for new tools)
- Workflow composition for multi-step automation
- AI agents for autonomous task execution

---

## ✨ Key Features

- 🔍 **Tool Discovery**: Browse and filter AI tools by category
- ⚙️ **Schema-Driven Config**: Add new tools through JSON configuration
- 🔗 **Workflow Composer**: Chain multiple tools into sequences
- 🛡️ **Secure API Keys**: Server-side key management
- 🚀 **AI Agents**: Plan and execute complex tasks autonomously
